# Local Workspaces

Create and edit named configurations for local Git checkouts. Validate
the checkout, base ref, checks and execution settings before saving. Discover
the conventional harborist.settings.yaml when no override is entered.
Store defaults and optional GitHub repository in the local control directory.

Choose a Workspace in New Run to reuse its configuration. Harborist freezes
each Run through the existing capture path. Keep manual submission available.

Browser verification saved a temporary Workspace using `~/Code/harborist`
and confirmed that New Run preselected it with its checkout and base ref.
